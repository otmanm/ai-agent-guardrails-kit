# Framework benchmark (Phase 0, honest by construction)

The goal of this directory is **not** a finished, paid, cross-framework benchmark. It is the honest Phase 0 package: the harness, the standardized attacks, the tests that can be run for free, and a matrix that labels every cell as measured, sourced, inferred, or not-runnable. Nothing here needs money, Docker, or large downloads. Where the real benchmark needs those, this package says so and gives the exact steps, instead of faking a result.

## What is here

| File | What it is |
|---|---|
| [attacks/](attacks/) | The five abuse paths as concrete, inert input fixtures. The standardized payloads any benchmark feeds. |
| [run-local.sh](run-local.sh) | Runs only the free, no-infra tests and writes what was actually run. |
| [vm-isolation-demo.js](vm-isolation-demo.js) | A dependency-free, measured test that open-dynamic-workflows' `node:vm` isolation is not a security boundary. |
| [MATRIX.md](MATRIX.md) | The frameworks-by-paths matrix, every cell labeled, with reproduction steps for the not-runnable cells. |
| [LOCAL-RESULTS.md](LOCAL-RESULTS.md) | Generated by `run-local.sh`: the cells that were actually measured here. |

## Run it

```bash
bash benchmark/run-local.sh
```

It re-runs the kit's attack matrix and the `node:vm` escape demo, and writes `LOCAL-RESULTS.md`. No keys, no network, no Docker.

## What was measured versus read

Measured here: the kit's own guard layer against all five paths (see [../tests/attack-matrix/](../tests/attack-matrix/)), and open-dynamic-workflows' `node:vm` isolation boundary. Everything else in the matrix is sourced from each project's own docs and code, or inferred from its architecture, and is clearly labeled as such. See [../VERIFICATION.md](../VERIFICATION.md) for the same run-versus-read split at the repo level.

## Why Phase 0 stops here

A full measured benchmark would drive each framework with a live model against the attacks and average over runs. That needs a paid LLM budget, Docker and several GB of disk for OpenHands, and acceptance of model nondeterminism. Faking those cells as if they were measured would be the exact unverifiable claim this whole repository exists to avoid. So Phase 0 ships the scaffolding and the honest labels, and the not-runnable cells wait for the infra, each with the command to fill it in.
